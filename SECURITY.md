# Security

The public demo runs bounded local computation. It does not execute submitted code, access external incident systems, or store inputs server-side. Avoid including confidential material in exported runs or issue reports.

For a vulnerability, use GitHub's private vulnerability reporting if enabled for this repository. Otherwise open an issue requesting a private contact channel without exploit details or secrets. Do not post credentials or personal data.

Supported version: the current main branch. Security-relevant changes must preserve input validation, the content security policy, text-only rendering, and resource bounds.
